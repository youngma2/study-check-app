가족 동기화 · 알림 설정

Supabase 에서 두 번만 붙여넣으면 폰끼리 이어지고, 앱을 닫아도 알림이 옵니다.

1. 표 만들기 (SQL 한 번)

공부 목록 · 💬 우리 가족 한마디 · 🔔 알림 구독 표가 한 번에 만들어집니다.

  1. Supabase 대시보드 → 왼쪽 SQL Editor → New query
  2. 아래 SQL 전체 복사 누르고 붙여넣기
  3. 오른쪽 아래 Run (또는 Ctrl/⌘ + Enter)
  4. 이 앱을 다시 열면 가족끼리 실시간 동기화가 켜집니다

-- ============================================================================
-- 공부 체크 (Study Check) — Supabase 스키마 · 가족 실시간 동기화
--
-- 실행 방법
--   Supabase Dashboard → SQL Editor → 아래 전체를 붙여넣고 [Run] 한 번.
--   여러 번 실행해도 안전합니다(이미 있는 행은 건드리지 않습니다).
--
-- 실행하면 바로 되는 것
--   · 우리 가족 공부방(아빠·엄마·첫째·둘째)과 이번 주 샘플 숙제가 들어갑니다.
--   · 아래 링크를 각자 폰에서 열면 로그인 없이 바로 그 사람 시점으로 열립니다.
--       아빠   https://youngma2.github.io/study-check-app/#as=mem_dad
--       엄마   https://youngma2.github.io/study-check-app/#as=mem_mom
--       첫째   https://youngma2.github.io/study-check-app/#as=mem_child1
--       둘째   https://youngma2.github.io/study-check-app/#as=mem_child2
--   · 숙제 체크(완료)·추가·삭제가 폰끼리 실시간으로 반영됩니다(새로고침 없음).
--   · 💬 우리 가족 한마디 — 아빠·엄마·아이 누구나 일정이나 전할 말을 남기고,
--     새 글은 다른 폰에 바로 뜨며 앱 위쪽에 알림 배너로 나타납니다.
--
-- 권한 (앱 + DB 이중으로 막습니다)
--   부모(아빠·엄마): 추가·수정·삭제·완료 되돌리기 — 부모 관리 PIN 필요
--   아이(첫째·둘째): 자기 숙제 추가, 자기 숙제 완료 체크(시간 기록). 삭제·수정·되돌리기 불가
--
-- 부모 관리 PIN
--   · 4자리 PIN 은 이 파일에 적지 않습니다(공개 저장소). 아래 5번 주석을 보고
--     `study_set_parent_pin` 으로 한 번만 정하면 됩니다.
--   · 저장은 public.family_secrets 에 bcrypt 해시(crypt + gen_salt('bf'))로만 하고,
--     RLS 정책을 하나도 만들지 않아 anon 키로는 읽을 수 없습니다.
--
-- 구조
--   families ─┬─ family_members
--             ├─ tasks
--             ├─ family_notes (💬 우리 가족 한마디 — 부모·아이 누구나 남기는 알림판)
--             ├─ family_secrets (부모 관리 PIN 해시 · 앱에서 직접 읽지 않음)
--             ├─ push_subscriptions (🔔 기기별 백그라운드 알림 구독 · 앱에서 직접 읽지 않음)
--             └─ push_config (🔔 알림 함수 주소·VAPID 공개키 — 공개키 한 줄만 앱이 읽음)
--   읽기는 누구나(가족 링크를 아는 기기), 쓰기는 아래 RPC 로만 가능하게 해 두고
--   RPC 안에서 역할(parent/child)과 PIN 을 검사합니다.
-- ============================================================================

-- (식별자 생성은 PostgreSQL 13+ 기본 함수인 gen_random_uuid() 를 씁니다.)

-- ----------------------------------------------------------------------------
-- 0. 확장 — PIN 해시용 pgcrypto (bcrypt)
--    (extensions 스키마는 Supabase 에 이미 있습니다. 스키마를 새로 만들지 않습니다.)
-- ----------------------------------------------------------------------------

do $$
begin
  -- Supabase 는 보통 extensions 스키마에 이미 들어 있습니다(그러면 그냥 넘어갑니다).
  -- (스키마 생성 권한이 없는 환경도 있어 `create schema` 는 시도하지 않습니다.)
  begin
    create extension if not exists pgcrypto with schema extensions;
  exception
    when others then
      begin
        create extension if not exists pgcrypto;
      exception
        when others then
          -- 로컬 테스트용 PostgreSQL 에 pgcrypto 가 없어도 나머지 스키마는 그대로 만듭니다.
          raise notice 'pgcrypto 확장을 설치하지 못했습니다: %', sqlerrm;
      end;
  end;
end;
$$;

-- 🔔 백그라운드 알림 트리거가 Edge Function 을 부를 때 쓰는 pg_net.
--   (확장 자체가 `net` 스키마를 만들기 때문에, 등록 위치와 상관없이 net.http_post 로 부릅니다.)
do $$
begin
  begin
    create extension if not exists pg_net with schema extensions;
  exception
    when others then
      begin
        create extension if not exists pg_net;
      exception
        when others then
          raise notice 'pg_net 확장을 켜지 못했습니다(백그라운드 알림만 꺼집니다): %', sqlerrm;
      end;
  end;
end;
$$;

create table if not exists public.families (
  id         text primary key,
  name       text not null check (length(btrim(name)) between 1 and 60),
  created_at timestamptz not null default now()
);

create table if not exists public.family_members (
  id         text primary key,
  family_id  text not null references public.families (id) on delete cascade,
  name       text not null check (length(btrim(name)) between 1 and 30),
  role       text not null check (role in ('parent', 'child')),
  grade      text,
  emoji      text not null default '🙂',
  color      text not null default 'sky' check (color in ('sky', 'violet', 'rose', 'amber')),
  presets    jsonb not null default '[]'::jsonb, -- [{ "title": "...", "subject": "math" }]
  created_at timestamptz not null default now()
);

create table if not exists public.tasks (
  id          text primary key,
  family_id   text not null references public.families (id) on delete cascade,
  member_id   text not null references public.family_members (id) on delete cascade,
  title       text not null check (length(btrim(title)) between 1 and 120),
  subject     text not null default 'etc',
  due_date    date not null,
  status      text not null default 'todo'
              check (status in ('todo', 'pending_verification', 'verified')),
  note        text,
  created_by  text references public.family_members (id) on delete set null,
  verified_by text references public.family_members (id) on delete set null,
  verified_at timestamptz, -- 완료 체크한 시각 (앱이 '오후 8:42 완료' 로 보여 줍니다)
  created_at  timestamptz not null default now(),
  updated_at  timestamptz not null default now()
);

-- 3. RPC — 앱이 쓰는 유일한 쓰기 통로. actor(누가)를 받아 역할을 검사합니다.

-- PIN 일치 여부(내부용). anon 에게는 열지 않고, 아래 RPC 들이 security definer 로 부릅니다.
create or replace function public.study_pin_is_valid(p_family_id text, p_pin text)
returns boolean
language sql
stable
security definer
set search_path = public, extensions
as $$
  select exists (
    select 1
      from public.family_secrets s
     where s.family_id = p_family_id
       and p_pin is not null
       and btrim(p_pin) <> ''
       and crypt(btrim(p_pin), s.parent_pin_hash) = s.parent_pin_hash
  );
$$;

-- 부모 관리 PIN 확인. 맞으면 true, 틀리면 false.
-- 아직 PIN 을 정하지 않았으면 안내 문구와 함께 오류를 냅니다(앱이 그대로 보여 줍니다).
create or replace function public.study_verify_parent_pin(p_family_id text, p_pin text)
returns boolean
language plpgsql
security definer
set search_path = public, extensions
as $$
declare
  v_hash text;
begin
  select parent_pin_hash into v_hash
    from public.family_secrets
   where family_id = p_family_id;

  if v_hash is null then
    raise exception '부모 관리 PIN이 아직 설정되지 않았어요. Supabase SQL Editor에서 PIN 설정 SQL을 한 번 실행해 주세요.'
      using errcode = 'P0002';
  end if;

  if p_pin is null or btrim(p_pin) = '' then
    return false;
  end if;

  return crypt(btrim(p_pin), v_hash) = v_hash;
end;
$$;

-- 부모 관리 PIN 정하기/바꾸기.
--   · 처음 정할 때:   study_set_parent_pin('fam_our_home', '새PIN')
--   · 나중에 바꿀 때: study_set_parent_pin('fam_our_home', '새PIN', '지금PIN')
create or replace function public.study_set_parent_pin(
  p_family_id  text,
  p_new_pin    text,
  p_current_pin text default null
)
returns boolean
language plpgsql
security definer
set search_path = public, extensions
as $$
declare
  v_new  text := btrim(coalesce(p_new_pin, ''));
  v_hash text;
begin
  if v_new !~ '^[0-9]{4}$' then
    raise exception '부모 관리 PIN은 숫자 4자리로 정해 주세요.' using errcode = '22023';
  end if;

  if not exists (select 1 from public.families where id = p_family_id) then
    raise exception '가족을 찾을 수 없습니다.' using errcode = 'P0002';
  end if;

  select parent_pin_hash into v_hash
    from public.family_secrets
   where family_id = p_family_id;

  -- 이미 정해져 있으면 지금 쓰는 PIN 을 알아야 바꿀 수 있습니다.
  if v_hash is not null then
    if p_current_pin is null or crypt(btrim(p_current_pin), v_hash) <> v_hash then
      raise exception '지금 쓰는 부모 관리 PIN이 맞지 않습니다.' using errcode = '42501';
    end if;
  end if;

  insert into public.family_secrets (family_id, parent_pin_hash, updated_at)
  values (p_family_id, crypt(v_new, gen_salt('bf')), now())
  on conflict (family_id) do update
    set parent_pin_hash = excluded.parent_pin_hash,
        updated_at      = now();

  return true;
end;
$$;

-- 공부 항목 추가: 부모는 아무 아이에게나, 아이는 자기 것만.
create or replace function public.study_add_task(
  p_actor_id  text,
  p_member_id text,
  p_title     text,
  p_subject   text,
  p_due_date  date,
  p_note      text default null,
  p_id        text default null
)
returns public.tasks
language plpgsql
security definer
set search_path = public
as $$
declare
  v_actor  public.family_members;
  v_target public.family_members;
  v_task   public.tasks;
  v_title  text := btrim(coalesce(p_title, ''));
begin
  select * into v_actor from public.family_members where id = p_actor_id;
  if not found then
    raise exception '사용자를 찾을 수 없습니다. 링크를 다시 확인해 주세요.' using errcode = '42501';
  end if;

  select * into v_target
  from public.family_members
  where id = p_member_id and family_id = v_actor.family_id;
  if not found then
    raise exception '같은 가족 구성원에게만 추가할 수 있습니다.' using errcode = '42501';
  end if;

  if v_actor.role <> 'parent' and v_actor.id <> v_target.id then
    raise exception '내 공부만 추가할 수 있습니다.' using errcode = '42501';
  end if;

  if v_title = '' then
    raise exception '무엇을 공부하는지 적어 주세요.' using errcode = '22023';
  end if;

  insert into public.tasks (id, family_id, member_id, title, subject, due_date, status, note, created_by)
  values (
    coalesce(nullif(btrim(p_id), ''), 't_' || replace(gen_random_uuid()::text, '-', '')),
    v_actor.family_id,
    v_target.id,
    v_title,
    coalesce(nullif(btrim(p_subject), ''), 'etc'),
    p_due_date,
    'todo',
    nullif(btrim(p_note), ''),
    v_actor.id
  )
  returning * into v_task;

  return v_task;
end;
$$;

-- 공부 항목 수정: 부모만.
create or replace function public.study_update_task(
  p_actor_id text,
  p_task_id  text,
  p_title    text,
  p_subject  text,
  p_due_date date,
  p_note     text default null
)
returns public.tasks
language plpgsql
security definer
set search_path = public
as $$
declare
  v_actor public.family_members;
  v_task  public.tasks;
  v_title text := btrim(coalesce(p_title, ''));
begin
  select * into v_actor from public.family_members where id = p_actor_id;
  if not found then
    raise exception '사용자를 찾을 수 없습니다. 링크를 다시 확인해 주세요.' using errcode = '42501';
  end if;
  if v_actor.role <> 'parent' then
    raise exception '항목 수정은 부모님만 할 수 있습니다.' using errcode = '42501';
  end if;

  select * into v_task from public.tasks where id = p_task_id and family_id = v_actor.family_id;
  if not found then
    raise exception '항목을 찾을 수 없습니다. 새로고침해 주세요.' using errcode = 'P0002';
  end if;
  if v_title = '' then
    raise exception '항목 이름을 비워 둘 수 없습니다.' using errcode = '22023';
  end if;

  update public.tasks
     set title      = v_title,
         subject    = coalesce(nullif(btrim(p_subject), ''), subject),
         due_date   = p_due_date,
         note       = nullif(btrim(p_note), ''),
         updated_at = now()
   where id = v_task.id
  returning * into v_task;

  return v_task;
end;
$$;

-- 상태 변경: 완료 체크는 아이도 자기 숙제에 할 수 있고(시각 기록), 되돌리기는 부모 + PIN.
create or replace function public.study_set_task_status(
  p_actor_id text,
  p_task_id  text,
  p_status   text,
  p_pin      text default null
)
returns public.tasks
language plpgsql
security definer
set search_path = public, extensions
as $$
declare
  v_actor public.family_members;
  v_task  public.tasks;
begin
  select * into v_actor from public.family_members where id = p_actor_id;
  if not found then
    raise exception '사용자를 찾을 수 없습니다. 링크를 다시 확인해 주세요.' using errcode = '42501';
  end if;

  select * into v_task from public.tasks where id = p_task_id and family_id = v_actor.family_id;
  if not found then
    raise exception '항목을 찾을 수 없습니다. 새로고침해 주세요.' using errcode = 'P0002';
  end if;

  if p_status not in ('todo', 'pending_verification', 'verified') then
    raise exception '알 수 없는 상태입니다.' using errcode = '22023';
  end if;

  if v_task.status = p_status then
    return v_task;
  end if;

  -- 완료 체크: 아이도 자기 숙제는 스스로 완료할 수 있습니다. 완료한 시각을 그대로 기록합니다.
  if p_status = 'verified' then
    if v_actor.role <> 'parent' and v_task.member_id <> v_actor.id then
      raise exception '내 숙제만 완료할 수 있습니다.' using errcode = '42501';
    end if;

    update public.tasks
       set status = 'verified', verified_by = v_actor.id, verified_at = now(), updated_at = now()
     where id = v_task.id
    returning * into v_task;

    return v_task;
  end if;

  -- 여기부터는 완료를 푸는 쪽(되돌리기 / 요청 취소)
  if v_task.status = 'verified' then
    if v_actor.role <> 'parent' then
      raise exception '완료를 되돌리는 건 부모님만 할 수 있습니다.' using errcode = '42501';
    end if;
    if not public.study_pin_is_valid(v_actor.family_id, p_pin) then
      raise exception '부모 관리 PIN이 필요합니다. 앱에서 관리 잠금을 풀고 다시 시도해 주세요.' using errcode = '42501';
    end if;
  elsif v_actor.role <> 'parent' and v_task.member_id <> v_actor.id then
    raise exception '내 공부만 바꿀 수 있습니다.' using errcode = '42501';
  end if;

  update public.tasks
     set status = p_status, verified_by = null, verified_at = null, updated_at = now()
   where id = v_task.id
  returning * into v_task;

  return v_task;
end;
$$;

create or replace function public.study_delete_task(
  p_actor_id text,
  p_task_id  text,
  p_pin      text default null
)
returns void
language plpgsql
security definer
set search_path = public, extensions
as $$
declare
  v_actor public.family_members;
begin

);

  on public.push_subscriptions (family_id);

returns trigger
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_url  text;
  v_key  text;
  v_hook text;
begin
  select value into v_url  from public.push_config where key = 'function_url';
  select value into v_key  from public.push_config where key = 'publishable_key';
  select value into v_hook from public.push_config where key = 'hook_secret';

  if coalesce(v_url, '') = '' or coalesce(v_hook, '') = '' then
    return new;  -- 알림 설정 전
  end if;

  begin
    perform net.http_post(
      url := v_url,
      body := jsonb_build_object('note_id', new.id),
      headers := jsonb_build_object(
        'Content-Type', 'application/json',
        'apikey', coalesce(v_key, ''),
        'x-study-hook', v_hook
      ),
      -- 첫 호출은 함수가 깨어나는 데 몇 초 걸립니다(그래도 응답을 기다리지 않고 큐에 들어갑니다).
      timeout_milliseconds := 10000
    );
  exception
    when others then
      -- pg_net 미설치·일시 오류: 알림만 건너뜁니다.
      null;
  end;

  return new;
end;
$$;

-- 승급 한 칸 기록 + (큰 티어면) 상자 + 축하 한마디(→ 폰 푸시)
--   같은 칸은 한 번만 만들어지므로, 폰 여러 대에서 동시에 불러도 알림은 한 번입니다.
-- ---------------------------------------------------------------------------
create or replace function public.study_tier_promotion(
  p_actor_id text,
  p_member_id text,
  p_season    text,
  p_level     integer,
  p_notify    boolean default true
)
returns jsonb
language plpgsql
security definer
set search_path = public
as $$
declare
  v_actor     public.family_members;
  v_member    public.family_members;
  v_rank      integer;
  v_div       integer;
  v_tier      text;
  v_event     public.family_tier_events;
  v_settings  public.family_reward_settings;
  v_pool      integer[];
  v_minutes   integer;
  v_id        text;
  v_today     text;
  v_note_id   text;
  v_author    text;
  v_title     text;
  v_div_text  text;
  v_last      text;
  v_josa      text;
  v_content   text;
  v_noted     boolean := false;
begin
  select * into v_actor from public.family_members where id = p_actor_id;
  if not found then
    raise exception '사용자를 찾을 수 없습니다. 링크를 다시 확인해 주세요.' using errcode = '42501';
  end if;

  select * into v_member
    from public.family_members
   where id = p_member_id and family_id = v_actor.family_id;
  if not found then
    raise exception '같은 가족 구성원의 티어만 기록할 수 있습니다.' using errcode = '42501';
  end if;
  if v_member.role <> 'child' then
    raise exception '티어는 아이에게만 있습니다.' using errcode = '22023';
  end if;

  if p_season is null or p_season !~ '^[0-9]{4}-(0[1-9]|1[0-2])$' then
    raise exception '시즌은 YYYY-MM 형식이어야 합니다.' using errcode = '22023';
  end if;
  if p_level is null or p_level < 0 or p_level > 15 then
    raise exception '티어 단계는 0~15 사이여야 합니다.' using errcode = '22023';
  end if;

  if p_level = 0 then
    -- 0 칸(브론즈 III)은 모두의 시작 칸이라 승급이 아닙니다.
    return jsonb_build_object('created', false, 'noted', false, 'event', null);
  end if;

  v_rank := (p_level / 3) + 1;
  if v_rank > 6 then
    v_rank := 6;
  end if;
  v_div := case when v_rank >= 6 then 0 else 3 - (p_level % 3) end;
  v_tier := (array['bronze', 'silver', 'gold', 'platinum', 'diamond', 'master'])[v_rank];
  v_id := 'ev_' || p_member_id || '_' || p_season || '_' || p_level::text;

  select * into v_event from public.family_tier_events where id = v_id;
  if found then
    return jsonb_build_object('created', false, 'noted', false, 'event', to_jsonb(v_event));
  end if;

  -- 큰 티어가 바뀔 때(실버 III·골드 III·플래티넘 III·다이아 III·마스터)만 상자 하나.
  -- 세부 단계(III→II→I)는 기록만 남기고 상자는 없습니다.
  if v_rank >= 2 and (p_level % 3) = 0 then
    select * into v_settings from public.family_reward_settings where family_id = v_actor.family_id;
    v_pool := coalesce(nullif(v_settings.pool, '{}'::integer[]), array[5, 10, 15, 20]);

    with candidates as (
      select value,
             case when v_rank >= 4 then ord * ord else ord end as weight
        from unnest(v_pool) with ordinality as t(value, ord)
       where value between 1 and 120
    )
    select value into v_minutes
      from candidates
     order by -ln(1 - random()) / weight
     limit 1;
  end if;

  insert into public.family_tier_events
    (id, family_id, member_id, season, tier, tier_rank, level, division, box_minutes)
  values
    (v_id, v_actor.family_id, v_member.id, p_season, v_tier, v_rank, p_level, v_div, v_minutes)
  on conflict (id) do nothing
  returning * into v_event;

  if v_event.id is null then
    select * into v_event from public.family_tier_events where id = v_id;
    return jsonb_build_object('created', false, 'noted', false, 'event', to_jsonb(v_event));
  end if;

  -- 승급 알림: 가족 알림판에 축하 한마디 → 기존 트리거가 폰 푸시를 보냅니다.
  --   글쓴이(author_id)는 부모로 둡니다 — 아이 기기에서 승급이 잡혀도 그 아이 폰에도 알림이 가도록.
  --   화면에는 '아빠' 가 아니라 '🐣 쪼꼬' 로 보이게 author_kind = 'jjokko' (8번).
  if p_notify then
    if v_actor.role = 'parent' then
      v_author := v_actor.id;
    else
      select id into v_author
        from public.family_members
       where family_id = v_actor.family_id and role = 'parent'
       order by created_at, id
       limit 1;
      v_author := coalesce(v_author, v_actor.id);
    end if;

    v_today := to_char((now() at time zone 'Asia/Seoul')::date, 'YYYY-MM-DD');
    v_note_id := 'n_' || v_today || '_tier_' || p_member_id || '_' || p_season || '_' || p_level::text;

    v_title := case v_rank
                 when 1 then '브론즈' when 2 then '실버' when 3 then '골드'
                 when 4 then '플래티넘' when 5 then '다이아' else '마스터' end;
    v_div_text := case v_div when 3 then ' III' when 2 then ' II' when 1 then ' I' else '' end;

    v_last := right(v_member.name, 1);
    if v_last ~ '[가-힣]' and (ascii(v_last) - 44032) % 28 = 0 then
      v_josa := '가';
    else
      v_josa := '이가';
    end if;

    v_content := '🎉 ' || v_member.name || v_josa || ' [' || v_title || v_div_text || '] 티어로 승급했어요!'
      || case when v_minutes is not null then ' 🎁 뽑기 상자가 열렸어요!' else '' end;

    insert into public.family_notes (id, family_id, author_id, author_kind, content)
    values (v_note_id, v_actor.family_id, v_author, 'jjokko', left(v_content, 300))
    on conflict (id) do nothing;
    v_noted := found;
  end if;

  return jsonb_build_object('created', true, 'noted', v_noted, 'event', to_jsonb(v_event));
end;
$$;

--
--   · 글쓴이(`author_id`)는 그대로 부모로 둡니다 — 그래야 폰 푸시가 모든 가족 폰
--     (아이 폰 포함)으로 갑니다. 화면 표시만 `author_kind = 'jjokko'` 로 바꿉니다.
--   · 앱은 `author_kind` 를 읽어 '🐣 쪼꼬' 로 그리고, 본문 앞의 `🐣 쪼꼬:` 는 덜어냅니다.
--   · 여러 번 실행해도 안전합니다(표·제약·트리거·RPC 모두 if not exists / create or replace).

-- 8-1. 표시용 열: 'member'(가족이 쓴 글) | 'jjokko'(쪼꼬가 올린 자동 알림)

    select 1

-- 8-2. 예전 방식(본문이 '🐣 쪼꼬: …' 로 시작)으로 올린 글도 자동으로 쪼꼬 글로.
--      (다른 자동화·지난 스크립트가 study_add_note 로 올려도 그대로 동작합니다)
create or replace function public.study_note_before_insert_jjokko()
returns trigger
language plpgsql
as $$
declare
  v_prefix   constant text := '^\s*(?:🐣\s*)?쪼꼬\s*[:：]\s*';
  v_body     text := btrim(coalesce(new.content, ''));
  v_stripped text;
begin
  if new.author_kind = 'member' and v_body ~ v_prefix then
    v_stripped := btrim(regexp_replace(v_body, v_prefix, ''));
    -- 접두사만 있던 글은 지우지 않습니다(본문 1자 이상 규칙 유지).
    if v_stripped <> '' then
      new.author_kind := 'jjokko';
      new.content := left(v_stripped, 300);
    end if;
  end if;
  return new;
end;
$$;

drop trigger if exists study_note_before_insert_jjokko on public.family_notes;
create trigger study_note_before_insert_jjokko
  before insert on public.family_notes
  for each row execute function public.study_note_before_insert_jjokko();

-- 8-3. 쪼꼬 명의로 한마디 남기기 — 부재중 전화·통화 결과처럼 쪼꼬가 남기는 글.
--      p_actor_id 는 가족 확인용(보통 부모 id). 화면에는 '🐣 쪼꼬' 로 보입니다.

  v_div       integer;

  v_event     public.family_tier_events;

  v_pool      integer[];
  v_minutes   integer;
  v_id        text;
  v_today     text;
  v_note_id   text;
  v_author    text;
  v_title     text;
  v_div_text  text;
  v_last      text;
  v_josa      text;
  v_content   text;

  select * into v_actor from public.family_members where id = p_actor_id;
  if not found then
    raise exception '사용자를 찾을 수 없습니다. 링크를 다시 확인해 주세요.' using errcode = '42501';

  if v_rank >= 2 and (p_level % 3) = 0 then

    v_pool := coalesce(nullif(v_settings.pool, '{}'::integer[]), array[5, 10, 15, 20]);

             case when v_rank >= 4 then ord * ord else ord end as weight
        from unnest(v_pool) with ordinality as t(value, ord)

     order by -ln(1 - random()) / weight

  end if;

    if v_actor.role = 'parent' then
      v_author := v_actor.id;
    else
      select id into v_author
        from public.family_members
       where family_id = v_actor.family_id and role = 'parent'
       order by created_at, id
       limit 1;
      v_author := coalesce(v_author, v_actor.id);
    end if;

    v_today := to_char((now() at time zone 'Asia/Seoul')::date, 'YYYY-MM-DD');
    v_note_id := 'n_' || v_today || '_tier_' || p_member_id || '_' || p_season || '_' || p_level::text;

    v_title := case v_rank
                 when 1 then '브론즈' when 2 then '실버' when 3 then '골드'
                 when 4 then '플래티넘' when 5 then '다이아' else '마스터' end;
    v_div_text := case v_div when 3 then ' III' when 2 then ' II' when 1 then ' I' else '' end;

    v_last := right(v_member.name, 1);
    if v_last ~ '[가-힣]' and (ascii(v_last) - 44032) % 28 = 0 then
      v_josa := '가';
    else

    end if;

function b64urlEncode(bytes: Uint8Array): string {
  let binary = '';
  for (let i = 0; i < bytes.length; i += 1) binary += String.fromCharCode(bytes[i]);
  return btoa(binary).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');
}

function b64urlDecode(text: string): Uint8Array {
  const normalized = text.replace(/-/g, '+').replace(/_/g, '/').trim();
  const padded = normalized + '='.repeat((4 - (normalized.length % 4)) % 4);
  const binary = atob(padded);
  const bytes = new Uint8Array(binary.length);
  for (let i = 0; i < binary.length; i += 1) bytes[i] = binary.charCodeAt(i);
  return bytes;
}

/* 작은 도우미                                                         */
/* ------------------------------------------------------------------ */

function concatBytes(...parts: Uint8Array[]): Uint8Array {
  const total = parts.reduce((sum, part) => sum + part.length, 0);
  const out = new Uint8Array(total);
  let offset = 0;
  for (const part of parts) {
    out.set(part, offset);
    offset += part.length;
  }
  return out;
}

function uint32(value: number): Uint8Array {
  return new Uint8Array([(value >>> 24) & 0xff, (value >>> 16) & 0xff, (value >>> 8) & 0xff, value & 0xff]);
}

/** TS 의 BufferSource 검사만 통과시키는 얇은 캐스팅(런타임 동작 없음). */
function view(bytes: Uint8Array): BufferSource {
  return bytes as unknown as BufferSource;
}

async function hmacSha256(keyBytes: Uint8Array, data: Uint8Array): Promise<Uint8Array> {
  const key = await crypto.subtle.importKey('raw', view(keyBytes), { name: 'HMAC', hash: 'SHA-256' }, false, [
    'sign',
  ]);
  return new Uint8Array(await crypto.subtle.sign('HMAC', key, view(data)));
}

/** HKDF(Extract + Expand) — RFC 5869 */
async function hkdf(ikm: Uint8Array, salt: Uint8Array, info: Uint8Array, length: number): Promise<Uint8Array> {
  const prk = await hmacSha256(salt, ikm);
  const blocks: Uint8Array[] = [];
  let block: Uint8Array = new Uint8Array(0);
  let size = 0;
  for (let counter = 1; size < length; counter += 1) {
    block = await hmacSha256(prk, concatBytes(block, info, new Uint8Array([counter])));
    blocks.push(block);
    size += block.length;
  }
  return concatBytes(...blocks).slice(0, length);
}

/* 본문 암호화 (RFC 8291 · aes128gcm)                                   */
/* ------------------------------------------------------------------ */

const RECORD_SIZE = 4096;
const INFO_PREFIX = encoder.encode('WebPush: info');
const CEK_INFO = encoder.encode('Content-Encoding: aes128gcm');
const NONCE_INFO = encoder.encode('Content-Encoding: nonce');

/**
 * 구독(p256dh·auth) 하나에 보낼 암호문을 만듭니다.
 * 돌려주는 바이트가 그대로 push 서비스로 가는 본문입니다.
 */
async function encryptPayload(
  payload: Uint8Array,
  p256dhBase64: string,
  authBase64: string,
): Promise<Uint8Array> {
  const uaPublic = b64urlDecode(p256dhBase64); // 기기 공개키 65바이트
  const authSecret = b64urlDecode(authBase64); // 인증 비밀값 16바이트
  if (uaPublic.length !== 65 || uaPublic[0] !== 0x04) {
    throw new Error('구독 공개키(p256dh) 형식이 올바르지 않습니다.');
  }

  // 서버(보내는 쪽)의 일회용 ECDH 키
  const ephemeral = await crypto.subtle.generateKey({ name: 'ECDH', namedCurve: 'P-256' }, true, [
    'deriveBits',
  ]);
  const asPublic = new Uint8Array(await crypto.subtle.exportKey('raw', ephemeral.publicKey));
  const uaKey = await crypto.subtle.importKey(
    'raw',
    view(uaPublic),
    { name: 'ECDH', namedCurve: 'P-256' },
    false,
    [],
  );
  const ecdhSecret = new Uint8Array(
    await crypto.subtle.deriveBits({ name: 'ECDH', public: uaKey }, ephemeral.privateKey, 256),
  );

  // IKM = HKDF(auth_secret, ecdh_secret, "WebPush: info" || 0x00 || ua_public || as_public, 32)
  const ikm = await hkdf(
    ecdhSecret,
    authSecret,
    concatBytes(INFO_PREFIX, new Uint8Array([0]), uaPublic, asPublic),
    32,
  );

  const salt = crypto.getRandomValues(new Uint8Array(16));
  const cek = await hkdf(ikm, salt, concatBytes(CEK_INFO, new Uint8Array([0])), 16);
  const nonce = await hkdf(ikm, salt, concatBytes(NONCE_INFO, new Uint8Array([0])), 12);

  // 마지막 레코드 표시(0x02)를 본문 끝에 붙입니다.
  const plaintext = concatBytes(payload, new Uint8Array([0x02]));
  const key = await crypto.subtle.importKey('raw', view(cek), 'AES-GCM', false, ['encrypt']);
  const ciphertext = new Uint8Array(
    await crypto.subtle.encrypt({ name: 'AES-GCM', iv: view(nonce), tagLength: 128 }, key, view(plaintext)),
  );

  // aes128gcm 헤더: salt(16) | rs(4) | idlen(1) | keyid(=as_public)
  return concatBytes(salt, uint32(RECORD_SIZE), new Uint8Array([asPublic.length]), asPublic, ciphertext);
}

/**
 * push 서비스에 붙일 Authorization 헤더 값.
 * `vapid t=<ES256 JWT>, k=<공개키>`
 */
async function vapidAuthHeader(
  endpoint: string,
  keys: VapidKeys,
  subject: string,
  nowMs: number = Date.now(),
): Promise<string> {
  const audience = new URL(endpoint).origin;
  const header = { typ: 'JWT', alg: 'ES256' };
  const claims = {
    aud: audience,
    exp: Math.floor(nowMs / 1000) + 12 * 60 * 60, // Apple 은 24시간 이내만 받습니다.
    sub: subject,
  };

  const signingInput = `${b64urlEncode(encoder.encode(JSON.stringify(header)))}.${b64urlEncode(
    encoder.encode(JSON.stringify(claims)),
  )}`;

  const { kty, crv, x, y, d } = keys.privateJwk;
  const privateKey = await crypto.subtle.importKey(
    'jwk',
    { kty, crv, x, y, d },
    { name: 'ECDSA', namedCurve: 'P-256' },
    false,
    ['sign'],
  );
  const signature = new Uint8Array(
    await crypto.subtle.sign({ name: 'ECDSA', hash: 'SHA-256' }, privateKey, encoder.encode(signingInput)),
  );

  return `vapid t=${signingInput}.${b64urlEncode(signature)}, k=${keys.publicKey}`;
}

/** VAPID 키 한 쌍(서명용 P-256). 처음 한 번만 만들어 DB 에 저장합니다. */
async function generateVapidKeys(): Promise<VapidKeys> {
  const pair = await crypto.subtle.generateKey({ name: 'ECDSA', namedCurve: 'P-256' }, true, [
    'sign',
    'verify',
  ]);
  const jwk = await crypto.subtle.exportKey('jwk', pair.privateKey);
  const raw = new Uint8Array(await crypto.subtle.exportKey('raw', pair.publicKey));
  return {
    publicKey: b64urlEncode(raw),
    privateJwk: { kty: 'EC', crv: 'P-256', x: jwk.x, y: jwk.y, d: jwk.d },
  };
}

async function rest<T = unknown>(path: string, init: RequestInit = {}): Promise<T | null> {
  const res = await fetch(`${PROJECT_URL}/rest/v1/${path}`, {
    method: init.method ?? 'GET',

    body: init.body as BodyInit | undefined,
  });
  const text = await res.text();
  if (!res.ok) throw new Error(`DB ${res.status} ${text.slice(0, 300)}`);
  return text ? (JSON.parse(text) as T) : null;
}

/** VAPID 키를 읽고, 없으면 만들어 저장합니다(동시 호출이 겹쳐도 한 쌍만 남습니다). */
async function ensureVapidKeys(): Promise<VapidKeys> {
  const publicKey = await configValue('vapid_public_key');
  const privateJwkRaw = await configValue('vapid_private_jwk');
  if (publicKey && privateJwkRaw) {
    return { publicKey, privateJwk: JSON.parse(privateJwkRaw) as JsonWebKey };
  }

  const generated = await generateVapidKeys();
  await rest('push_config?on_conflict=key', {
    method: 'POST',
    headers: { Prefer: 'resolution=ignore-duplicates,return=representation' },
    body: JSON.stringify([
      { key: 'vapid_public_key', value: generated.publicKey },
      { key: 'vapid_private_jwk', value: JSON.stringify(generated.privateJwk) },
    ]),
  });

  // 먼저 저장된 쪽이 이깁니다(경쟁 상태에서도 모두 같은 키를 씁니다).
  const storedPublic = await configValue('vapid_public_key');
  const storedPrivate = await configValue('vapid_private_jwk');
  if (storedPublic && storedPrivate) {
    return { publicKey: storedPublic, privateJwk: JSON.parse(storedPrivate) as JsonWebKey };
  }
  return generated;
}

interface SubscriptionRow {
  endpoint: string;
  p256dh: string;
  auth: string;

interface NoteRow {
  id: string;
  family_id: string;
  author_id: string;
  /** 'jjokko' = 쪼꼬가 자동으로 올린 알림(티어 승급·부재중 전화 등) — 본문에 쪼꼬 이름을 씁니다. */
  author_kind?: string | null;
  content: string;
  created_at: string;
}

/** 한마디가 붙는 날짜(앱의 알림판과 같은 규칙: id 에 박힌 날짜 → 없으면 한국 날짜). */
export function noteDate(note: Pick<NoteRow, 'id' | 'created_at'>): string {
  const fromId = /^n_(\d{4}-\d{2}-\d{2})_/.exec(note.id);
  if (fromId) return fromId[1];
  const created = new Date(note.created_at);
  if (Number.isNaN(created.getTime())) return '';
  // 한국 시간(KST, UTC+9) 기준 날짜 — Intl 없이 계산해 런타임 ICU 에 기대지 않습니다.
  return new Date(created.getTime() + 9 * 60 * 60 * 1000).toISOString().slice(0, 10);
}

function shorten(text: string, max: number): string {
  const flat = text.replace(/\s+/g, ' ').trim();
  return flat.length > max ? `${flat.slice(0, max - 1)}…` : flat;
}

async function sendToSubscription(
  sub: SubscriptionRow,
  payload: unknown,
  keys: VapidKeys,
): Promise<number> {
  const body = await encryptPayload(
    new TextEncoder().encode(JSON.stringify(payload)),
    sub.p256dh,
    sub.auth,
  );
  const authorization = await vapidAuthHeader(sub.endpoint, keys, SUBJECT);
  const res = await fetch(sub.endpoint, {
    method: 'POST',
    headers: {
      Authorization: authorization,
      'Content-Encoding': 'aes128gcm',
      'Content-Type': 'application/octet-stream',
      TTL: '86400',
      Urgency: 'high',
    },
    // Uint8Array 를 그대로 본문으로 보냅니다(TS 의 BodyInit 검사만 통과시키는 캐스팅).
    body: body as unknown as BodyInit,
  });
  // 응답 본문을 읽어 두어야 연결이 정리됩니다.
  await res.text().catch(() => '');
  return res.status;
}

async function dropSubscription(endpoint: string): Promise<void> {
  await rest(`push_subscriptions?endpoint=eq.${encodeURIComponent(endpoint)}`, { method: 'DELETE' });
}

Deno.serve(async (req: Request): Promise<Response> => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: CORS_HEADERS });

  const url = new URL(req.url);
  let body: Record<string, unknown> = {};
  if (req.method === 'POST') {
    try {
      body = (await req.json()) as Record<string, unknown>;
    } catch {
      body = {};
    }
  }
  const action = String(body.action ?? url.searchParams.get('action') ?? 'note');

  try {
    if (!PROJECT_URL || !SERVICE_KEY) {
      return json({ ok: false, error: 'SUPABASE_URL / 서버 키가 없습니다.' }, 500);
    }

    if (action === 'config' || action === 'init') {
      const keys = await ensureVapidKeys();
      return json({ ok: true, publicKey: keys.publicKey });
    }

    if (action === 'health') {
      const [subs, config] = await Promise.all([
        rest<Array<{ endpoint: string }>>('push_subscriptions?select=endpoint'),
        rest<Array<{ key: string }>>('push_config?select=key'),
      ]);
      return json({
        ok: true,
        subscriptions: subs?.length ?? 0,
        configKeys: (config ?? []).map((row) => row.key),
        serviceKeyPresent: Boolean(SERVICE_KEY),
      });
    }

    const noteId = String(body.note_id ?? url.searchParams.get('note_id') ?? '');
    if (!noteId) return json({ ok: false, error: 'note_id 가 필요합니다.' }, 400);

    const expectedHook = await configValue('hook_secret');
    const hook = req.headers.get('x-study-hook') ?? url.searchParams.get('hook') ?? '';
    if (!expectedHook || hook !== expectedHook) {
      return json({ ok: false, error: 'forbidden' }, 403);
    }

    // 한마디 하나에 한 번만: 아직 안 보낸 글이면 지금 보낸다고 먼저 표시합니다.
    const claimed = await rest<NoteRow[]>(
      `family_notes?id=eq.${encodeURIComponent(noteId)}&push_sent_at=is.null&select=id,family_id,author_id,author_kind,content,created_at`,
      { method: 'PATCH', body: JSON.stringify({ push_sent_at: new Date().toISOString() }) },
    );
    if (!claimed || claimed.length === 0) return json({ ok: true, skipped: 'already-sent' });
    const note = claimed[0];

    // 너무 옛 글(트리거 재시도 등)은 울리지 않습니다.
    const age = Date.now() - Date.parse(note.created_at);
    if (Number.isFinite(age) && age > 15 * 60_000) return json({ ok: true, skipped: 'stale' });

    const [subs, authors, keys] = await Promise.all([
      rest<SubscriptionRow[]>(
        `push_subscriptions?family_id=eq.${encodeURIComponent(note.family_id)}&select=endpoint,p256dh,auth,member_id`,
      ),
      rest<Array<{ id: string; name: string }>>(
        `family_members?id=eq.${encodeURIComponent(note.author_id)}&select=id,name`,
      ),
      ensureVapidKeys(),
    ]);

    const targets = (subs ?? []).filter((sub) => sub.member_id !== note.author_id);
    if (targets.length === 0) return json({ ok: true, sent: 0, note: note.id });

    // 쪼꼬가 자동으로 올린 알림은 '아빠' 가 아니라 '🐣 쪼꼬' 이름으로 보여 줍니다.
    const authorName =
      note.author_kind === 'jjokko' ? '🐣 쪼꼬' : (authors?.[0]?.name ?? '가족');
    const date = noteDate(note);
    const payload = {
      title: '💬 우리 가족 한마디',
      body: `${authorName}: ${shorten(note.content, 160)}`,
      tag: `study-note-${note.id}`,
      noteId: note.id,
      date,
      // 누르면 그 날짜의 알림판으로 바로 열립니다(앱의 deepLinkDate 가 받는 형식).
      url: `./#date=${date}&note=${encodeURIComponent(note.id)}`,
    };

    const results = await Promise.allSettled(
      targets.map(async (sub) => {
        const status = await sendToSubscription(sub, payload, keys);
        if ([401, 403, 404, 410].includes(status)) {
          await dropSubscription(sub.endpoint);
        }
        return { status };
      }),
    );

    let sent = 0;
    let dropped = 0;
    const statuses: number[] = [];
    for (const result of results) {
      if (result.status === 'fulfilled') {
        statuses.push(result.value.status);
        if (result.value.status >= 200 && result.value.status < 300) sent += 1;
        if ([401, 403, 404, 410].includes(result.value.status)) dropped += 1;
      } else {
        statuses.push(0);
      }
    }

    return json({ ok: true, note: note.id, targets: targets.length, sent, dropped, statuses });
  } catch (error) {
    return json({ ok: false, error: error instanceof Error ? error.message : String(error) }, 500);
  }
